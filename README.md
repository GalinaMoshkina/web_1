# my home, my rules, my coffee
Сайт с товарами для дома, учебный проект  
  
https://galinamoshkina.github.io/web_1/  
  
Каталог из 11 товаров с фото, названием и ценой.  
Товары можно добавлять в корзину, удалять, изменять их количество в корзине.  
Можно оформить заказ.  
Все данные корзины сохраняются в `localStorage`, поэтому не пропадают при перезагрузке страницы.  

index.html - главная страница  
script.js - логика карточек товаров, корзины, оформления заказа  
css -> style.css - стили и адаптивность  
css -> cover.png - обложка сайта
